openalex-corpus 0.1.2 can be installed without Python and keeps itself up to date.
Collection, parsing and exports are unchanged from 0.1.1.

### New
- **Standalone builds** of the command-line tool for macOS (Apple silicon and Intel)
  and Linux (`.deb`, or a `.tar.gz` with a per-user `install.sh`), plus the wheel and
  sdist. On Windows use the Linux build inside WSL2: the harvester relies on POSIX file
  semantics (directory fsync, atomic renames of open files). They bundle Python and the core dependencies (httpx, PyMuPDF, pdfplumber,
  lxml, pandas, pyarrow). The optional Docling and OCRmyPDF extras and the external
  GROBID, Java, Tesseract and Ghostscript tools are **not** bundled - install them as
  described in the README when you need those parsers.
- **`openalex-corpus self-update`**: checks the latest GitHub release; a standalone
  build downloads the file for your system, verifies it against `SHA256SUMS.txt` and
  replaces itself as soon as the command exits (`--check-only` just reports). pip and
  source installs are told the command to run instead.
- **Daily update check**: once a day any command also asks GitHub in the background
  (one anonymous request; only the program name and version are sent). A standalone
  build installs a newer release after the command has finished; other installs print
  one line saying how to update. `OPENALEX_CORPUS_NO_UPDATE=1` turns this off; CI runs
  and tests never check.
- **`openalex-corpus version`** prints the version and how this copy was installed.

### First start of an unsigned build
- **macOS**: the files of a downloaded archive are quarantined; run
  `xattr -dr com.apple.quarantine openalex-corpus` in the unpacked folder once (or allow
  it under **System Settings → Privacy & Security**).
